# Dataset setup

The coursework report identifies the source as:

**Twitter Emotion Dataset: Unveiling the Emotional Tapestry of Social Media**  
Kaggle dataset by Adham Elkomy (2024)

Dataset page:  
https://www.kaggle.com/datasets/adhamelkomy/twitter-emotion-dataset/data

The report records **416,809 English-language text samples** with six labels:

| Label | Emotion |
|---:|---|
| 0 | Sadness |
| 1 | Joy |
| 2 | Love |
| 3 | Anger |
| 4 | Fear |
| 5 | Surprise |

Download the dataset yourself and place the CSV here as:

```text
data/emotions.csv
```

Required columns:

```text
text
label
```

The dataset is intentionally excluded from Git by `.gitignore`.
